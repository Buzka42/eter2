# Archive

Documents that were accurate when they were written and have been superseded.
Kept, not deleted, because a decision whose reasoning is gone gets relitigated
every few months — and because several of these record *why* something was not
done, which is the kind of thing no code comment ever carries.

Nothing here describes the app as it is. For that, read the five living
documents in the parent directory, starting with `HANDOFF.md`.
